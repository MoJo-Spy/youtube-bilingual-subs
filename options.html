YouTube Bilingual Subtitles

Translate YouTube subtitles using your own OpenAI-compatible model.

The OpenAI-compatible endpoint root. Don't include /chat/completions.

Tips

  • Only videos with subtitles (CC) will be translated — the extension reads the existing subtitle track from YouTube. Turn captions on in the player.
  • After changing settings, reload the YouTube tab for them to take effect.
  • Translations are cached locally per video / model / language — no repeat charges when you rewatch.
  • The extension batches 20 lines per request to the model.
